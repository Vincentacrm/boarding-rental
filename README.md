# Boarding House and Apartment Rental Listing System

A web-based system for browsing boarding houses and apartments, viewing property details, and sending inquiries.

## Project Description

This project aims to help users find available boarding houses and apartments online. Property owners and administrators can manage property listings and inquiries.

## Technologies Used

* React.js
* Laravel REST API
* MySQL
* PHP
* JavaScript
* Git and GitHub

## Main Features

* User registration and login
* Browse and search property listings
* View property details
* Send rental inquiries
* Manage properties
* Manage and update inquiry statuses
* Admin and regular user roles

## Project Structure

* `backend/` — Laravel REST API
* `frontend/` — React.js application (to be created)
